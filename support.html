常见问题

English ↓
支持什么设备和语言？

支持 iOS 17 及以上的 iPhone，无需注册账号。默认跟随系统语言，支持简体中文和 English；可在设置 → 语言与外观手动切换。

在哪里选择图片、相机或文件？

在今天或班表点导入班表，再选择来源：

  • 截图 / 照片：从系统相册选中具体图片。
  • 相机拍照 / 扫描：拍摄纸质班表。
  • Excel / PDF / CSV：从系统“文件”选择文件。

支持图片、PDF、无宏且未加密的 .xlsx 和 UTF-8 CSV；旧 .xls、宏文件和加密文件需先转换。

识别不正确怎么办？

先旋转或裁剪图片，保留清晰的姓名和日期表头，再选择自己的行及月份。同名时核对日期范围；表格文件需核对工作表、表头行和姓名列。

逐日修正结果，预览保存结果并确认各日期后再保存。看不清或未知的内容不会自动视为休息，也可点更换班表重选来源。

免费次数和 Pro 怎么计算？

每自然月共用 5 次成功自动操作，用于新班表导入或新轮班批量保存；一次整份/整批计 1 次。取消、失败、重复、零变化不扣，手动编辑不计次。撤销不退次数。

Pro 可用时提供不限次自动操作，价格以 App 和 Apple 确认页面为准；显示“订阅尚未就绪”时暂不能购买。购买恢复与管理入口在设置 → 自动安排额度。删除 App 不会自动取消订阅。

如何备份？提醒或日历有问题怎么办？

在设置 → 备份与恢复导出 JSON，原始附件请另外保存。应用没有自建云同步。遇到数据读取错误，先保留备份，勿直接删除 App。

提醒和日历需主动开启；检查系统权限、专注模式及 App 内提示。通知送达和小组件刷新由系统控制，日历同步与本机保存分开。

如何反馈问题？

到 GitHub Issues 提交 App 版本、iPhone/iOS 版本、操作步骤和错误信息。导入问题可附匿名化小样。

Issues 公开可见，请勿提交真实排班表、员工姓名、密码或支付信息。

仍有问题？请描述操作步骤，并隐藏私人信息。

Frequently asked questions

Back to top ↑
Which devices and languages are supported?

iPhone with iOS 17 or later. No app account is required. The interface follows your system language by default and supports English and Simplified Chinese. Change it in Settings → Language and appearance.

Where do I choose an image, camera, or file?

Tap Import a schedule in Today or Schedule, then choose:

  • Screenshots / photos: Select the exact image in the system photo picker.
  • Camera / scan: Capture a paper roster.
  • Excel / PDF / CSV: Select a document in Files.

Supported formats include images, PDFs, unencrypted macro-free .xlsx, and UTF-8 CSV. Convert legacy .xls, macro-enabled, or encrypted files first.

What if recognition is incorrect?

Rotate or crop the image while keeping names and date headers readable. Select your row and month; check the date range when names repeat. For spreadsheets, verify the worksheet, header row, and name column.

Correct each date and Preview changes before confirming and saving. Unreadable or unknown content is not treated as rest. Use Change source to choose another file.

How do the free allowance and Pro work?

Five successful automated actions are shared each calendar month between new roster imports and new bulk schedules. A whole import or batch counts once. Cancelled, failed, duplicate, or unchanged operations use none; manual editing is unmetered. Undo does not refund an action.

When available, Pro provides unlimited automated actions. Check the app and Apple’s confirmation sheet for prices. Purchases are unavailable when the app says subscriptions are not ready. Restore and management options are in Settings → Automated action allowance. Deleting the app does not cancel a subscription.

How do I back up data or troubleshoot reminders and Calendar?

Export JSON in Settings → Backup and recovery; keep original attachments separately. The app has no developer-operated cloud sync. If data cannot be read, preserve your backups instead of immediately deleting the app.

Enable reminders and Calendar explicitly, then check system permissions, Focus, and in-app messages. Notification delivery and widget refresh depend on the system. Calendar sync is separate from local saving.

How do I report a problem?

Open a GitHub Issue with the app version, iPhone/iOS version, steps, and error message. An anonymized sample can help with import problems.

Issues are public. Never post real rosters, employee names, passwords, or payment details.

Still need help? Share the steps and remove private information.
